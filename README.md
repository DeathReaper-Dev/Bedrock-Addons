# Axiom Studios — High-Retention Bedrock Add-on Bundle

Welcome to the official repository of the production-ready Bedrock Add-on bundle. This repository contains 5 highly scalable, fully optimized projects designed specifically for viral algorithmic traffic and maximum engagement.

# 🌟 Visual Preview & Features

# 1. Giant Diamond Tools
* **Concept:** 10x scaled giant diamond tools using native attachable properties.
* **Stats:** Attack range expanded to 15 blocks. Sword Damage: 100 | Axe Damage: 150.

# 2. Abyss Ascension
* **Concept:** Hardcore survival minigame engine where a lethal Void Abyss rises every 2 seconds.
* **Mechanics:** 4x4 chunk arena sealed with a global barrier roof at Y=320. Built-in dynamic void damage loop.

# 3. Ore Flowers
* **Concept:** Automated crop-farming economy featuring 10 unique resource-generating flowers (Diamond, Netherite, Iron).
* **Optimization:** Planar scanning and position-caching every 5 seconds (0% performance impact on mobile devices).

# 4. Max Enchants
* **Concept:** Every enchantable item entering the inventory instantly receives up to 4 random max-tier vanilla enchantments.
* **Logic:** Anti-infinite loop caching system for instant player gratification.

# 5. Atomic Stacks
* **Concept:** Completely removes durability from Iron, Diamond, and Netherite armor/weapons, allowing them to stack up to 64.
* **Progression Scale:** 
  * Stack of 2-4 ➡️ Resistance I / Strength I
  * Stack of 8 ➡️ Special Ability: Health Boost & Speed Unlocked!
  * Stack of 64 ➡️ Absolute God Mode (100% Damage Reduction & One-Shot Power)

# 📂 Bundle Structure
* **AtomicStacks** — Core behavior pack that removes item durability, enables items to stack up to 64, and introduces dynamic cumulative status effects based on precise stack tiers.
* **MagicInventory** (Max Enchants) — Script-driven inventory scanner that safely applies compatible maximum-tier vanilla enchantments to items upon entering the player's inventory.
* **OreFlowers** — Automated crop-farming economy mod featuring 10 unique resource-generating flowers with strict position-caching optimization.
* **AbyssAscension** (Abyss) — Hardcore survival minigame engine with a progressive world-border barrier, sealed roof logic, and custom void damage loop.
* **Giant Diamond Tools** — Visual and gameplay meta-modifier expanding mining and attack range using native attachable properties.
